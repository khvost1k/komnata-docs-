# Установка

## Требования

Для работы сервиса нужен Python 3.8 или новее.

## Установка пакета

Установите пакет из каталога PyPI:

```bash
pip install komnata
```

## Первый запуск

Скопируйте файл конфигурации по умолчанию в рабочую папку под именем `komnata.yaml` и запустите сервис:

```bash
komnata serve
```

После запуска откройте в браузере адрес `http://127.0.0.1:8080`.
Первый юзер, который войдёт в систему, получает права администратора.
