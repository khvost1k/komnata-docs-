# Работа с сервисом

## Запуск

Чтобы запустить сервис в фоновом режиме, выполните:

```bash
komnata start --daemon
```

## Остановка и перезапуск

Остановите процесс сервиса средствами операционной системы и запустите его снова.
Параметры, которые можно изменить перед перезапуском, перечислены в разделе [Настройка](configure.md).

## Вход в веб-интерфейс

Чтобы залогиниться, откройте адрес сервиса в браузере и кликнуть кнопку «Войти».
