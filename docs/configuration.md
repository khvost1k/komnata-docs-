# Настройка

Сервис читает параметры из файла `komnata.yaml` при каждом запуске.
Путь к файлу можно изменить параметром `--config`.

Перед изменением настроек убедитесь, что:

- сервис остановлен;
- у вас есть резервная копия файла базы данных.

| Параметр | Описание | По умолчанию |
|---|---|---|
| `host` | Адрес, на котором сервис принимает подключения | `127.0.0.1` |
| `port` | Порт подключения | `8000` |
| `database` | Путь к файлу базы данных | `./komnata.db` |
| `cache_ttl` | Время жизни кэша расписания, с | `300` |
| `booking.max_duration_hours` | Максимальная длительность одной брони, ч | `4` |
| `booking.allow_weekends` | Разрешить бронирование в выходные | `false` |

Пример файла:

```yaml
host: 0.0.0.0
port: 8000
booking:
  max_duration_hours: 2
```

!!! note "Примечание"
    Изменения вступают в силу после перезапуска сервиса.

Как перезапустить сервис, описано в разделе [Работа с сервисом](usage.md).
