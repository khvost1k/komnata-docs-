# Решение проблем

## Порт занят

Если при запуске появляется сообщение о том, что порт занят, другой процесс уже использует этот порт.
Задайте другой порт в параметре `port` или остановите этот процесс.

## Ошибка в файле конфигурации

Ошибки в файле конфигурации проще всего найти до запуска сервиса.
