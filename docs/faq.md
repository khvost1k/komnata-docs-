# Вопросы и ответы

## Как изменить порт?

По умолчанию сервис слушает порт 8080.
Чтобы изменить порт, задайте параметр `port` в файле конфигурации.

## Можно ли бронировать комнаты в выходные?

Да, если в файле конфигурации задано `booking.allow_weekends: true`.

## Сервис не запускается. Что делать?

См. раздел [Решение проблем](troubleshooting.md).
