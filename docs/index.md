# Komnata

Komnata — сервис бронирования переговорных комнат для небольших офисов.
Сотрудники бронируют комнату через веб-интерфейс, а администратор управляет сервисом из командной строки.

Документация описывает версию 2.0.

- [Установка](install.md) — как установить и впервые запустить сервис.
- [Настройка](configuration.md) — все параметры файла конфигурации.
- [Работа с сервисом](usage.md) — команды для администратора.
- [Вопросы и ответы](faq.md) — частые вопросы.
