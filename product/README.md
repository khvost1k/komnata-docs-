# Исходные данные о продукте («источник истины»)

Продукт **komnata** вымышленный. Запускать его не нужно.
Файлы в этой папке заменяют вам работающую программу:

- `cli-help.txt` — что программа выводит по команде `komnata --help`;
- `komnata.default.yaml` — файл конфигурации по умолчанию;
- `../CHANGELOG.md` — журнал изменений.

Если документация в папке `docs/` расходится с этими файлами, права эти файлы.

Требования к окружению: Python 3.10 или новее.
