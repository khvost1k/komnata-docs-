# Журнал изменений komnata

## 2.0.0 — 2026-09-15

- Команда `start` переименована в `serve`, флаг `--daemon` заменён на `--background`.
- Порт по умолчанию изменён с 8080 на 8000.
- Удалён параметр `cache_ttl`: кэширование больше не используется.
- Добавлена команда `check-config`.
- Минимальная версия Python повышена до 3.10.

## 1.4.0 — 2026-03-02

- Добавлен параметр `booking.allow_weekends`.

## 1.3.0 — 2025-11-20

- Добавлены уведомления по электронной почте (`notifications.email_enabled`).
