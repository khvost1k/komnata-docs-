# Сравнение языков разметки (задание 5)

Положите в эту папку фрагмент страницы `docs/configuration.md`,
переписанный на reStructuredText (`configuration.rst`) или AsciiDoc (`configuration.adoc`).

Папка лежит вне `docs/`, поэтому MkDocs её не собирает.
Откройте файл на GitHub: сайт сам покажет его в оформленном виде.
